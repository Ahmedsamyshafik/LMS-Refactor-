------------------------------
A. CRITICAL ISSUES
------------------------------

1. Quiz Auto-Submit & UTC Timezone Bug

Affected Endpoints:
- /Quiz/Get/1
- /Quiz/Submit

المشكلة الأولى:
- بمجرد فتح الكويز، يتم تنفيذ Submit تلقائياً بعد حوالي ثانية واحدة.
- بعدها يتم تحويل المستخدم إلى صفحة HTTP 500.

السبب:
- السيرفر يقوم بتخزين وقت انتهاء الامتحان باستخدام UTC.
- المتصفح يتعامل مع الوقت باعتباره Local Time.
- نتيجة اختلاف التوقيت، يتم اعتبار الامتحان منتهياً فور فتحه.
- المشكلة تؤثر على الامتحانات التي تقل مدتها عن ساعتين وفقاً للاختبار.

المشكلة الثانية:
- عند تنفيذ Submit بإجابات فارغة، يحدث Exception.
- السيرفر يرجع HTTP 500.
- لا توجد معالجة صحيحة لقيم Null.

المطلوب:
- توحيد طريقة التعامل مع التوقيت باستخدام UTC.
- مراجعة تحويل الوقت بين السيرفر والمتصفح.
- معالجة الإجابات الفارغة وNull بشكل صحيح.
- منع تنفيذ Submit تلقائياً إلا عند انتهاء الوقت فعلياً.


2. Written Quiz Submission Forbidden

Affected Endpoint:
POST /Quiz/SubmitWritten

المشكلة:
- الطالب لا يستطيع تسليم الامتحان المقالي.
- الـ Endpoint محمي بصلاحية Admin فقط.
- الطالب يحتاج إلى الوصول إليه حتى يتمكن من تسليم إجاباته.

Additional Issue:

Page:
 /Account/AccessDenied

المشكلة:
- الصفحة غير موجودة أساساً.
- عند رفض صلاحية المستخدم، يتم توجيهه إلى صفحة غير موجودة.
- النتيجة: HTTP 404 وصفحة فارغة.

المطلوب:
- مراجعة Authorization Policy الخاصة بـ SubmitWritten.
- السماح للطالب بتسليم إجابته وفقاً للصلاحيات الصحيحة.
- إنشاء صفحة AccessDenied أو ضبط مسار التعامل مع رفض الصلاحيات.


3. Course Requests - Sensitive Data Exposure & CSRF

Affected Endpoint:
GET /CourseRequest/GetAll

المشكلة:
- الطالب يستطيع الوصول إلى قائمة جميع طلبات الالتحاق.
- يستطيع مشاهدة بيانات طلبات طلاب آخرين.
- البيانات تشمل:
  - أسماء الطلاب.
  - طلبات الالتحاق.
  - الأسعار.

Additional Issues:
- أزرار القبول والحذف ظاهرة للطالب.
- عمليات القبول والحذف يتم تنفيذها من خلال GET Links.

Security Risks:
- كشف بيانات شخصية ومالية لطلاب آخرين.
- إمكانية تنفيذ عمليات حساسة عن طريق GET.
- التعرض لهجمات CSRF.

المطلوب:
- حماية GetAll بصلاحيات Admin فقط.
- إخفاء أزرار الإدارة عن الطلاب.
- تحويل عمليات القبول والحذف إلى POST أو الطرق المناسبة مثل PUT وDELETE.
- تطبيق Anti-Forgery Protection على العمليات الحساسة.


4. Teacher PDF Upload Access Control

Affected Page:
 /material/index/1

المشكلة:
- الطالب يستطيع فتح فورم رفع ملفات PDF الخاص بالمدرس.
- الصفحة لا تمنع الوصول إليها بالشكل الصحيح.

ملاحظة:
- تم اختبار إمكانية فتح الفورم فقط.
- عملية رفع الملفات فعلياً لم يتم اختبارها.

المطلوب:
- مراجعة صلاحيات الوصول إلى صفحات رفع المواد.
- السماح للمدرس أو Admin فقط بالوصول إلى وظيفة الرفع.

- إخفاء تفاصيل Development Mode عن المستخدمين في Production.
- توحيد التعامل مع الأخطاء غير المتوقعة.
